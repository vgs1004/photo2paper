Photo to Papercraft

Upload a photo of any object. Get a printable sheet that you cut, fold and glue into a 3D model.

1 Connect to GitHub

Not connected

The page saves your photo into the repo, and GitHub builds the model there. It needs a GitHub access token. You only have to do this once.

How to get a token (2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Give it a name such as "papercraft", and choose an expiry.
  3. Under Repository access, pick Only select repositories, then choose photo2paper.
  4. Under Permissions → Repository, set Contents to Read and write and Actions to Read-only.
  5. Click Generate token, then copy it and paste it below.

The token is only sent to api.github.com. If you tick "Remember", it's kept in this browser only.
